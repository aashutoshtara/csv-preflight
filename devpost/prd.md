# CSV literal-value preflight — product requirements

## The Core Journey
1. Open a single workspace with purpose, local handling notice and limits. Select CSV or load a labelled synthetic sample.
2. See file name, counts, source hash and risk summary above a literal table. Keep the first record as data; use generic A/B/C coordinates.
3. Choose a finding to navigate to its record/cell. A detail panel shows location, exact JSON-escaped representation, length and risk explanation.
4. Generate an all-text review workbook. Reopen it in memory and compare expected strings/types; enable download only after verification.
5. Download original CSV, verified XLSX or a content-free receipt. Reset clears app state; reload starts empty.
Implements `scope.md > The Core Loop` and `scope.md > The Unique Kernel`.

## Features and Behavior

### Load and Preserve
Read strict UTF-8 CSV with comma delimiter, optional BOM, quoted commas/newlines and CRLF/LF. Retain original bytes separately. Never trim, normalize, infer types/headers or repair malformed quotes. Remove only the parser's synthetic extra record after a terminal line ending, never a trailing empty field or genuine blank record. Fixtures distinguish `a,b,\n`, `a\n\n`, `""` and a zero-byte file.
Acceptance: synthetic sample works; BOM/CRLF source downloads identically; invalid encoding/empty/malformed input receives an actionable error; replacement clears old output; limits never produce partial accepted data.

### Inspect Literal Values
Render 25 logical records per page, horizontally scroll wide tables, and number logical records rather than physical lines. Imported strings are text nodes, never HTML. Selected cells expose escaped text so line breaks and whitespace are visible.
Acceptance: zeros, long digits, quotes, commas, Unicode and multiline values remain unchanged; HTML/formula-like text stays inert; selection works with keyboard; inconsistent widths fail clearly.

### Understand Conversion Risks
Flag digit-only strings beginning with zero, digit-only strings longer than 15 digits, numeric scientific-notation shapes, and formula-like prefixes (=, +, -, @, allowing preceding whitespace). A cell can have several findings. Legitimate values can be flagged; an all-clear result only means these supported patterns were absent.
Acceptance: every fixture produces correct categories/coordinates; ordinary prose does not; negative-number warnings are conservative risks, not corruption claims. Finding filters do not mutate records.

### Export and Verify
Original download uses saved bytes. XLSX contains explicit strings, including the first record, with empty fields represented by blank cells within a declared rectangular data range; no formulas/macros/external links. Round-trip check generated bytes using the same workbook library: every nonempty value must be an exact string, and blank cells are equivalent to empty CSV strings only inside the expected rectangle. Preserve the declared logical dimensions even with entirely blank rows/trailing columns; then enable download. Receipt records version, limits, dimensions, risk counts, hashes and verification result, without cell contents.
Acceptance: original hash matches; required independent openpyxl check confirms fixture values/types, declared dimensions, blank equivalence and absence of formulas; failed verification disables workbook download and keeps original available. Native Excel/Sheets compatibility is unclaimed until observed.

## States and Boundaries
Empty → loading/checking → ready → generating/verifying → verified, with visible status and appropriate disabled actions. Errors explain the cause and offer another file or sample. Reject invalid UTF-8, malformed quoting, inconsistent widths, unsupported XML control characters, cells longer than 32,767 UTF-16 code units (a conservative explicit bound) and file/record/field limits. Async replacement must not attach stale results. Reset revokes download URLs and releases in-memory data. No localStorage or IndexedDB.

## Look and Feel
Agent recommendation: warm off-white canvas, dark slate text/navigation, restrained teal confirmation and amber risk accents. Use system sans-serif controls and monospace data, with no external fonts. Desktop table/detail split stacks on narrow screens. Text accompanies every color; labels, focus rings and polite status announcements are required. No chat UI or decorative imagery.
